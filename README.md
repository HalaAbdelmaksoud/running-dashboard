# Running Dashboard

A small Python website (Flask + pandas) with two dashboards built from running-log data.

## Run locally

Requires Python 3.10 or newer.

```bash
git clone https://github.com/<your-username>/running-dashboard.git
cd running-dashboard
python -m venv .venv
```

Activate the virtual environment, then install dependencies and start the app:

```bash
# Windows PowerShell
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000. It opens on the latest week.

## Data

The repository includes `data/running_log.csv`, which contains dummy running data
generated by Claude from an Excel workbook for demonstration purposes. It is not
a record of actual activity. To use your own log, replace it with a CSV export
that has the same column headers, then refresh the page.

## Training approach

I designed the dashboards around what I look for as a runner and what I wanted
to see in my own running log. They were created for demonstration purposes.
The running-log design and interval progression reflect my personal experience,
what I have read, and the approach I used to make progress. They are not based
on a scientific resource, and are not professional training or medical advice.

## Development process

I used vibe coding to build the pages. I provided directions for what each page
should contain and which charts to use to visualize the data.

## Pages

| Page | What it shows |
|---|---|
| **Weekly** (`/weekly`) | Week picker (or ‹ › arrows) and a **Day** filter. **All days** shows the week's KPIs vs last week, distance per day, the per-km pace of every run overlaid, the weekly pace and runs-per-week trends, and a table of the runs. **Pick a day** to get a line chart of that run's pace per km against its average, the km-split table, and a breakdown of how the run went (fastest/slowest km, negative or positive split). |
| **Monthly** (`/monthly`) | Month picker. KPIs vs last month, the pace of every run in the month, runs and distance per month, average pace and pace variation by month, the interval-type mix, and the weeks inside the month. |

Every chart has hover tooltips. Clicking a bar or point jumps to that week, month or run.

## Project layout

```
app.py          Flask routes: builds each dashboard's numbers and charts
analytics.py    Loads the CSV, weekly/monthly aggregation, insights text
charts.py       Bar, line and stacked-bar charts drawn as SVG in pure Python
templates/      Jinja HTML (base, weekly, monthly, shared macros)
static/         style.css (light + dark mode), tooltip.js (hover tooltips)
data/running_log.csv   The data. Same columns as the "Running Log" sheet
```

## Updating the data

Replace `data/running_log.csv` with a fresh CSV export of the sheet, keeping the same
column headers, and refresh the page. The data reloads on every request. Paces can be
`m:ss` (e.g. `8:51`) or `h:mm:ss`. Average pace and pace variation are recalculated
from duration, distance and the km splits, so they always match.
